Revisionshistorie

Version 1.4 · Standalone-HTML · S3-Origin Verfügbarkeitscheck

Version 1.4

  • Umgebung (Dev / Stage / Prod) wird vor der Prüfung gewählt – keine parallele Abfrage aller Umgebungen.
  • Stabilere Verfügbarkeitsprüfung: begrenzte Parallelität, Manifest-Checks für HLS/DASH (ohne schwere Player-Instanzen).
  • MP3-Prüfung über Audio-Element statt Video-Tag.
  • Zuverlässige Timeouts (kein Hängen bei vielen Renditions).

Version 1.3

  • Drei Auslieferungsverzeichnisse wählbar in der Kopfleiste (Mehrfachauswahl per Checkbox).
  • progressive/ – ohne GEO-Blocking; progressive_geo/ – mit GEO-Blocking; progressive_geo_dach/ – nur GEO-DACH.
  • Matrix gruppiert Ergebnisse je gewähltem Verzeichnis.

Version 1.2

  • Audio-IDs (AU-…): nur MP3, vereinfachte Übersicht, HTML5-Audio-Player.
  • Auslieferpfad-Segment progressive (statt ndr) für MP4, HLS, DASH und MP3.
  • TV-ID und AU-ID in einem Eingabefeld; automatische Erkennung.
  • AGENTS.md und GitLab-Repository origin-checker.

Version 1.1 (Renditions-Katalog LRA NDR)

  • Vollständiger Import aus renditions.xlsx (21 Einträge) für LRA NDR.
  • Katalog-Struktur pro LRA erweiterbar (lib/renditions-catalog.json, Import via tools/import-renditions.py).
  • Gruppen: Audio, AVC, HEVC, VP9, Flash (historisch, nicht prüfbar).
  • LRA-Auswahl in den erweiterten Optionen; Pfad-Segment wird aus der LRA abgeleitet.

Version 1.0 – Zweck

  • Prüfung der Verfügbarkeit von Videoinhalten auf den ARD-MCDN S3-Origin-Umgebungen Dev, Stage und Prod.
  • Unterstützung bei der Fehlersuche durch Anzeige von Ausspielpfad und vollständiger URL.

Eingabe

  • Suche über TV-ID (TV-…) oder Audio-ID (AU-…, nur MP3).
  • Automatische Bereinigung von Suffixen (z. B. .hq.mp4) und Pfadanteilen aus der Eingabe.
  • Pfad-Segment für Auslieferung: wählbar in der Kopfleiste (progressive, progressive_geo, progressive_geo_dach).

Verfügbarkeitsprüfung

  • Automatische Abfrage aller hinterlegten Renditions (AVC, HEVC, VP9 – siehe Katalog in renditions.xlsx).
  • Drei Auslieferungsformate je Rendition: Progressive Download (MP4), Adaptive HLS (M3U8), Adaptive DASH (MPD).
  • URL-Ableitung per Regex aus TV-ID, Datum und Verzeichnis (/{verzeichnis}/JJJJ/MMTT/).
  • Prüfung der gewählten Umgebung; Umschaltung Dev / Stage / Prod vor dem Start.
  • Kompakte Übersicht mit grünem Haken (verfügbar) und rotem Kreuz (nicht verfügbar).
  • HTTP-Prüfung im Browser (HEAD/GET), bei Bedarf Fallback über Video-, HLS- oder DASH-Probes.

Player

  • Separater Player-Bereich unter der Verfügbarkeitsübersicht.
  • Auswahl durch Klick auf eine Matrix-Zelle; Anzeige von Ausspielpfad und Status.
  • Wiedergabe für MP4 (nativ), MP3 (Audio-Element), HLS (hls.js / Safari nativ), DASH (dash.js).
  • Funktionen: Abspielen, Neu Laden, In neuem Tab öffnen, URL kopieren.

Technik

  • Einzelne HTML-Datei, plattformunabhängig (Doppelklick / Browser, ohne Node-Server).
  • Externe Abhängigkeit: hls.js und dash.js (jsDelivr), nur bei Bedarf geladen.
